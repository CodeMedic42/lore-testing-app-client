# @acme/contact-form

A small React contact form built from `@acme/ui-kit`.

`ContactForm` composes `Card`, `TextField` and `Button`, holding field state with
`useState`; `src/index.tsx` mounts it with `createRoot`.

## Stack

TypeScript, with Vite, Vitest and ESLint as dev dependencies. No build scripts are
defined — the sources are the artefact.
